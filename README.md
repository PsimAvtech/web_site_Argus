# ARGUS Website

Production-ready Next.js website based on the seven approved ARGUS screens.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Push the repository to GitHub and import it into Vercel. Vercel will detect Next.js automatically.

## Structure

- `app/` — application shell, metadata, sitemap and robots
- `components/sections/` — seven approved website screens
- `components/ui/` — shared navigation
- `public/images/screens/` — optimized screen artwork
